# Ограничения архива

## Происхождение

Канонический склад файлов:  
[Google Drive — ds_forum_damps](https://drive.google.com/drive/folders/1vu788RsUnWlqY_wzHBs2DaGKrJAve1Gy)  
(`DarkSide_forum.rar`, папки `Offline Explorer/`, `ds-alliance.ru/`).

Срез снят **Offline Explorer Enterprise 6.7**, целевой URL вида  
`http://ds-alliance.ru/forum/`, логин бота `history_bot`, даты файлов в основном **2014-04-03**.

Это HTML-зеркало ответов SMF, а не:

- файловое дерево установки SMF (`Sources/`, `Settings.php`);
- `mysqldump` / бэкап БД;
- полный каталог `Attachments/` сервера.

## Почему нельзя «просто поднять SMF»

| Нужно живому SMF | Есть в архиве |
|---|---|
| PHP + MySQL схема | Нет |
| Хеши паролей, права групп | Нет |
| Полные attachments | Частично (`dlattach`, аватары) |
| Приватные борды вне ACL бота | Нет |

Имеет смысл только **статика** или отдельный долгий проект парсинга HTML → импорт.

## Артефакты Offline Explorer

- `?` → `@` в именах файлов; `&` часто → `;` (стиль SMF) или `_` в ZIP-фрагментах.
- Каталоги `%&OvrN` — версии при перезаписи URL; скрипт очистки их сливает.
- `Descr.WD3` — служебные метки OE, в сайт не копируются.
- В исходнике есть `index.php@action=login2@...hash_passwrd=...` — **не публиковать**.

## Внешние ресурсы

Посты ссылаются на `../../i.imgur.com/...`, tumblr, fastpic и т.д.  
Очищенный сайт тащит сохранённые хосты рядом с `ds-alliance.ru/`, поэтому часть картинок жива.  
Всё, что OE не скачал (или уже 404 в 2014), останется битым.

Крупные одиночные файлы (например eve-files / justin.tv) раздувают релиз; при нехватке места можно пересобрать с `--forum-only` (только `ds-alliance.ru`) — картинки в постах пострадают сильнее.

## Кодировка

Страницы: **windows-1251**. Не перекодируйте массово в UTF-8 без иконовочного прохода — сломаете текст.

## ZIP с Google Drive

Тома `drive-download-*.zip` упираются в лимит **65535** записей ZIP и частично дублируют RAR с другими именами (`.html`). Канонический источник для сборки — **`DarkSide_forum-001.rar`**.
